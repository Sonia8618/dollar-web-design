# my-portfolio — GitHub Pages package

این بسته شامل صفحه مقاله و ۱۲ تصویر WebP بهینه‌شده است.

## انتشار
1. محتویات این پوشه را در ریشه مخزن `Sonia8618/my-portfolio` قرار دهید.
2. در GitHub به Settings → Pages بروید.
3. منبع انتشار را روی Deploy from a branch و شاخه `main` و پوشه `/ (root)` قرار دهید (یا اگر workflow موجود دارید، همان را بررسی کنید).
4. پس از تعیین دامنه اصلی، canonical، `og:url`، `og:image`، `CNAME` و `sitemap.xml` را با دامنه واقعی تکمیل کنید.

## نکته تصاویر
تصاویر اصلی قبلی از پنل‌های برش‌خورده با وضوح حدود 550×230 پیکسل تهیه شده بودند. این بسته آن‌ها را با برش 16:9 به WebP و اندازه 1200×675 تبدیل می‌کند؛ افزایش اندازه، جزئیات ازدست‌رفته را بازیابی نمی‌کند. برای کیفیت واقعی بهتر، باید ۱۲ تصویر را جداگانه در وضوح اصلی تولید کرد.

## دامنه
نام دقیق دامنه اختصاصی هنوز دریافت نشده است؛ بنابراین canonical و sitemap نهایی عمداً درج نشده‌اند تا URL اشتباه در گوگل ثبت نشود.
